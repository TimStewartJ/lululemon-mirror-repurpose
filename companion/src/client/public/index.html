Mirror Companion

USB setup, pairing, dashboard, Wi-Fi, and media for your Mirror.

0. Companion access

Only required when the companion is reachable over the LAN (not needed for the default loopback-only setup). Ask whoever configured the companion for the access token; it is kept only in this tab's session storage and sent as an X-Companion-Token header.

1. Connect over USB

Plug the Mirror in over USB and authorize debugging on-device if prompted.

      BLE provisioning (Web Bluetooth)

      Provision Wi-Fi and connect over Bluetooth Low Energy instead of USB, using your browser's Web Bluetooth support (Chrome/Edge on desktop or Android). The Mirror must be advertising its provisioning service. This must be started by clicking the button below directly (browsers require a user gesture to start a Bluetooth scan).
